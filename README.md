## 📖 О проекте

**«Змея и Лягушка»** — бесплатная 3D-аркада в браузере, созданная в рамках социального проекта **Anti-AI Shield**. Игрок управляет светящейся красной змеёй на стеклянном пруду и должен поймать хитрую лягушку **3 раза за 3 минуты**, используя прыжки и язык.

Игра работает **полностью офлайн** после первой загрузки, не содержит рекламы, микротранзакций, аналитики и навязчивых ИИ-алгоритмов. Это чистый, честный геймплей — как дань уважения классическим играм 90-х.

### 🎯 Цель игры
- 🐸 Поймать лягушку **3 раза** до истечения таймера (3:00)
- ⚡ Использовать **прыжок** и **язык** для атаки
- 🌿 Избегать столкновений с камышами и краем пруда (оглушение на 1.5 сек)
- 🏆 Получить награду «Красная змея» и отправить результат на Доску почёта

## ✨ Особенности

| Возможность | Описание |
|---|---|
| 🎨 **Стеклянный UI (Glassmorphism)** | Современный дизайн с размытием, полупрозрачными панелями и градиентами |
| 🌊 **Динамический пруд** | 50 кувшинок, камыши, водная поверхность с анимацией и частицами брызг |
| 🧠 **Умный ИИ-противник** | Лягушка реагирует на близость змеи: прыгает дальше и чаще, когда напугана |
| 📱 **Адаптивный интерфейс** | Идеально на ПК (клавиатура + мышь) и мобильных (тач-кнопки) |
| 🔊 **Иммерсивный звук** | Процедурные звуки через Web Audio API + тактильная отдача (вибрация) |
| 🌐 **Двуязычность** | Полный перевод на Русский и Английский |
| 💾 **PWA-ready** | Работает офлайн, можно добавить на рабочий стол |
| 🎁 **Система наград** | Доска почёта для победителей с защитой от читов (подпись токена) |
